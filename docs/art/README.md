Generated with the built-in image-generation tool for this interface. The wide painting is used on the opening screen; the transparent quill, Codex, drafts and lantern illustrations are reused on navigation, buttons and headers. WebP delivery copies keep the complete set under 180 KB. Text labels remain real accessible HTML.
